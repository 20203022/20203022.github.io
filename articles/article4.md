## 背景

我一直想做一个个人网站来展示作品和技术博客。传统开发方式大概需要一周，我决定用 Vibe Coding 的方式挑战 2 小时内完成。

## 技术选型

- **前端**：React 19 + Vite 8
- **后端**：Spring Boot 3.2 + Spring Security + JPA
- **数据库**：MariaDB
- **部署**：阿里云 2C2G + Nginx + systemd

## 开发过程

### 第一步：项目脚手架（10 分钟）

直接用自然语言描述项目结构需求，Claude Code 生成了完整的前后端项目骨架。

### 第二步：粒子网络背景（15 分钟）

描述视觉效果需求，Claude Code 写了一个 Canvas 粒子网络动画。

### 第三步：用户系统（30 分钟）

实现了注册/登录、JWT 认证、角色权限（Admin/User），包括前端的 AuthContext 和后端的 SecurityConfig。

### 第四步：博客和项目模块（30 分钟）

文章和项目的 CRUD、Markdown 渲染、代码高亮、分页、搜索、标签过滤。

### 第五步：评论和点赞（20 分钟）

评论系统、点赞切换、权限控制。

### 第六步：部署上线（15 分钟）

服务器配置、Nginx 反向代理、systemd 服务、数据库初始化。

## 关键经验

### 1. 描述要具体

不要说"做一个好看的首页"，而是说"做一个全屏 Hero 区域，包含大标题、打字机动画效果的副标题、两个 CTA 按钮，背景是粒子网络动画"。

### 2. 让 AI 先出方案

对于复杂功能，先让 AI 描述实现方案，确认无误后再让它写代码。

### 3. 善用上下文

Claude Code 会记住对话上下文。把设计决策和约束条件放在 CLAUDE.md 里，每次对话都能复用。

### 4. 你仍然是主导者

AI 是你的加速器，不是替代品。架构决策、安全考虑、性能优化这些需要你来把握方向。

## 成果

最终网站在 2 小时内上线：一个带粒子背景动画、中英文切换、用户系统、博客模块、评论点赞的全栈个人网站。

## 总结

Vibe Coding 不是魔法——它需要你对技术有足够的理解，能够清晰地描述需求，审查 AI 生成的代码。但一旦掌握了这种工作方式，生产力提升是巨大的。
